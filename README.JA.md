# K（rmc8）

## 自己紹介

東京を拠点に、プログラミングやテクノロジーに関する個人開発をしています。Webアプリや開発ツール、AI連携など、日々の課題を解決するものを幅広く作っています。

## 主なプロジェクト

### Open Notebook MCP Server

Open NotebookをAIアシスタントから操作するMCPサーバーです。ノートブックや資料、メモの管理、検索、質問などに対応しています。

### 個人ブログ

個人ブログを開発・運用しています。公開リポジトリではSvelteKitを使った旧サイトがあります。

## 技術領域

### Web開発

- Svelte、SvelteKit、Tailwind CSS
- Astroによるシンプルなページ作成
- GoやPythonによるAPI・バックエンド開発
- Webアプリとセルフホストサービスの連携

### AI・開発ツール

- MCPサーバーの設計と開発
- LangChain、LangGraph、Ollama
- Pythonによる自動化やデータ処理
- Obsidianなどの知識管理ツールとの連携

### インフラ・運用

- Dockerを使ったセルフホスト環境
- GitHub Actionsなどによる自動化
- Raspberry Piを含む小型機器でのサービス運用

## 開発で大切にしていること

- 新しい技術を実際に試し、使い続けられる形にする
- 保守しやすい設計と、わかりやすいドキュメントを心がける
- 作ったツールや知見をオープンソースで共有する
